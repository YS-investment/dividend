# 배당투자 기준서

웹 스크리너·포트폴리오 진단·배당투자 컨설턴트 스킬이 공통으로 따르는 판단 기준.

- **수치 원본은 [`config.py`](../config.py)** — 이 문서의 숫자는 "현재 값" 참고용. 기준 변경 시 config를 먼저 고치고 이 문서를 맞춘다
- **판정은 코드, 해석은 사람/LLM** — 아래 [적용] 항목은 코드가 이미 판정한 값을 그대로 쓴다
- 표기
  - **[적용]** 코드에 구현됨 (필터·점수·등급·신호)
  - **[표시]** 계산해서 보여주지만 필터·점수에 쓰지 않음
  - **[정성]** 데이터로 판정 불가 → 사람/LLM이 점검 (체크리스트는 §11)

---

## 0. 핵심 원칙

1. **배당률 > 금리** — 위험자산을 들고 있는 대가가 무위험 이자보다 커야 한다
2. **배당성장률 > 물가** — 실질 배당소득이 줄지 않아야 한다
3. **배당은 이익·현금흐름에서 나와야 한다** — 커버리지·부채·이자보상을 섹터 특성에 맞춰 본다
4. **삭감 이력은 가장 강한 경고** — 연속 증가 연수와 실제 지급 내역으로 이중 확인
5. **싸게 사되, 싼 이유를 의심한다** — 역사적 고배당률은 매수 신호이자 함정 신호
6. **종목이 아니라 포트폴리오로 판단** — 소득 집중·섹터 집중·지급월 공백을 본다
7. **세후·원화 기준으로 계산** — 한국 거주자 세금과 환율을 반영한 실수령액이 목표

## 1. 투자 대상 (유니버스)

미국 상장 배당주 중 아래 최소 조건을 통과한 종목. 현재 약 380종목.

- [적용] 배당률 ≥ **2%** (`UNIVERSE_MIN_YIELD`) — 배당성장주 포함 전 종목 공통 하한
- [적용] 연속 배당 증가 ≥ **5년** (`UNIVERSE_MIN_GROWTH_YEARS`)
- [적용] 1년 배당성장률 ≥ **3%** (`UNIVERSE_MIN_GROWTH_1Y`)
- [적용] 5년 배당 CAGR ≥ **5년 연환산 CPI** (`macro_benchmarks.json`, 현재 4.06%)
- 예외: 배당 귀족주·배당 왕족주·SCHD 편입 종목은 위 조건 없이 포함 (스크리너 단계에서 다시 걸러짐)
- 리츠·MLP 포함 — 배당성향 대신 현금흐름 커버리지로 평가 (§4)
- 제외: 한국 상장 주식, ETF(포트폴리오 진단에서만 조회·표시)

## 2. 거시 기준값

매 데이터 갱신 때 자동 갱신 (`modules/macro_benchmarks.py` → `data/macro_benchmarks.json`).

| 기준 | 정의 | 용도 | 현재 값 |
|---|---|---|---|
| 금리 기준 | 미국 10년물 국채 **3년 이동평균** (`^TNX`) | 고배당 트랙 배당률 하한 | 4.33% |
| 물가 기준 | CPI-U **5년 연환산** (FRED `CPIAUCSL`) | 5년 배당 CAGR 하한 | 4.06% |

- 3년 평균을 쓰는 이유: 10년물 단일 시점은 변동이 커서 기준이 매달 흔들림. 3개월물은 예금 수준이라 너무 낮음
- 조회 실패 시 마지막 성공 값 유지 → 그것도 없으면 config 기본값(4.5% / 3.0%)

## 3. 트랙별 기준

두 트랙은 같은 골격(배당률 → 성장률 → 연수 → 배당성향 → 점수)을 쓰고 기본값만 다르다.

| 항목 | 고배당 트랙 | 배당성장 트랙 |
|---|---|---|
| 목적 | 지금 받는 현금흐름 극대화 | 미래 배당(원금 대비 배당률) 극대화 |
| 배당률 하한 | **금리 기준(10년물 3년 평균)** | 2% |
| 5년 배당 CAGR 하한 | **CPI** | **max(5%, CPI)** |
| 1년 배당성장률 하한 | 3% | 5% |
| 연속 증가 / 무삭감 연수 | 5년 / 5년 | 10년 / 10년 |
| 배당성향 범위 (일반·에너지) | 20–70% | 15–60% |
| ROE 하한 | 0% | 8% |
| Chowder Rule | — | [적용] 배당률 ≥ 3% → 12 이상, 3% 미만 → 15 이상 |
| 시가총액 하한 | — | [적용·선택] **$200억 이상** 체크박스 (기본 꺼짐, `GROWTH_MIN_MARKET_CAP_USD`) |
| 점수 가중치 | 배당률 50 · 5년 CAGR 25 · 커버리지 25 | 5년 CAGR 60 · 배당률 40 |

- 5년 CAGR은 모두 **삭감 보정값**(`Div_CAGR_5Y_Adj`, §5) 기준
- Chowder Number = 배당률(%) + 보정 5년 CAGR(%)
- 기본값은 각 스크리너 페이지 위젯에 있음 — 금리·물가 연동 항목은 갱신 시 자동 반영

### 어떤 트랙을 쓸까

- **고배당**: 은퇴·생활비 등 지금 배당소득이 필요할 때, 투자 원금이 클 때
- **배당성장**: 적립 기간이 길 때, 연금저축 등 과세이연 계좌에서 복리로 굴릴 때
- 실제 포트폴리오는 둘을 섞는 경우가 많음 — 축적기에는 배당성장 비중↑, 인출기에는 고배당 비중↑

## 4. 탈락 기준 (게이트) — 섹터별

점수와 무관하게 하나라도 걸리면 제외. 데이터 결측은 "알 수 없음"으로 통과.

### 4-1. 섹터 분류

- REIT: Sector = Real Estate
- MLP: Industry에 Midstream 포함
- 유틸리티 / 은행(Industry가 Banks로 시작) / 기타 금융 / 에너지 / 그 외 일반

### 4-2. 섹터별 컷오프 (`SECTOR_RULES`)

| 섹터 | 순부채/EBITDA ≤ | 이자보상배율 ≥ | 커버리지 지표 | 커버리지 하한 | 배당성향 | EPS·ROE 게이트 |
|---|---|---|---|---|---|---|
| 일반 | 3.5 | 5 | FCF/배당 (3년 평균) | — | 슬라이더 범위 | 적용 |
| 에너지 | 2.0 | 5 | FCF/배당 (3년 평균) | — | 슬라이더 범위 | 적용 |
| 유틸리티 | 6.5 | 2 | 1/배당성향 | — | ≤ 80% | 적용 |
| REIT | 6.5 | 2 | 영업현금흐름/배당 (3년 평균) | **1.2배** | 면제 | 면제 |
| MLP | 6.5 | 2 | 영업현금흐름/배당 (3년 평균) | **1.2배** | 면제 | 면제 |
| 은행 | 면제 | 면제 | 1/배당성향 | — | ≤ 60% | 적용 |
| 기타 금융 | 3.5 | 5 | 1/배당성향 | — | ≤ 60% | 적용 |

- 유틸리티·REIT·MLP: 규제·장기 계약으로 현금흐름이 안정적 → 높은 부채 허용
- REIT·MLP: 감가상각이 커서 순이익·배당성향이 왜곡 → 영업현금흐름(AFFO 대용)으로 평가
- 은행: 부채가 곧 영업 자산 → 부채·FCF 지표 무의미, 배당성향으로만 평가
- 에너지: 원자재 가격에 이익이 출렁임 → 부채 한도를 가장 엄격하게

### 4-3. 공통 게이트

- [적용] **적자**: 최근 12개월 EPS ≤ 0 → 탈락 (REIT·MLP 면제)
- [적용] **ROE**: 트랙별 하한 미만 → 탈락. 음수 ROE는 통과(자사주 매입으로 자본이 음수인 경우가 대부분)
- [적용] **매출 추세**: **3년 연속 매출 감소** → 탈락 (`REVENUE_DECLINE_YEARS_FAIL`)
  - 한 해 감소나 정체는 통과 — 추세만 본다
- [표시] **매출·이익 동반 성장** 배지 (`Growth_Badge`): 매출 3년 CAGR > 0 AND EPS 3년 CAGR > 0
  - 탈락 기준은 아님 — "추세적 악화"만 탈락, "함께 성장"은 가산 신호

## 5. 배당 삭감 판정

- [적용] **삭감 감지**: 아래 두 방법이 **모두** 10% 넘는 감소를 같은 시기(±1년)에 잡아야 삭감으로 본다
  - 회차 기준: 같은 회차의 전년 대비 지급액
  - 연간 기준: 연도별 지급 총액
  - 특별배당(평소 지급액의 1.5배 초과)은 제외
- [적용] **연속 증가 10년 이상이면 삭감 없음으로 확정** (`CUT_CHECK_STREAK_YEARS`) — 데이터 오류로 인한 오탐 차단
- [적용] **`Cut_Flag`** = 삭감 감지 AND 연속 증가 < 10년
- [적용] **보정 5년 CAGR** (`Div_CAGR_5Y_Adj`)
  - 연속 증가 ≥ 10년 → 데이터 제공처 5년 CAGR 그대로
  - 그 외 → min(제공처 5년 CAGR, **고점 기준 5년 CAGR**)
  - 삭감 후 회복 구간의 기저효과(낮은 바닥 대비 높은 성장률)를 걷어낸다
- [적용] **위기 검증** (`Crisis_Passed`, `Crisis_Count`): 연속 증가 연수가 위기 여파 연도를 덮으면 통과
  - 기준 연도 (`CRISIS_YEARS`): 2000 IT버블 → 2001, 2008 금융위기 → 2009, 2020 코로나 → 2020
  - 통과 조건: 연속 증가 연수 ≥ 올해 − 기준 연도 (2026년 기준 25 / 17 / 6년)
  - 2008 통과 시 안전성 등급 가점 (§7)
  - 한계: 연속 증가 연수로 추정 — 위기 중 동결 후 재개한 종목은 미통과로 나옴

## 6. 점수 — 백분위

- [적용] 지표마다 **전체 유니버스 내 백분위(0–1)** → 가중합 × 100 = 0–100점
  - 결측은 중립 0.5
  - 극단값 하나가 다른 종목 점수를 왜곡하지 않음
- 점수는 **통과한 종목 간 순서**일 뿐, 탈락 기준을 대신하지 않는다
- 가중치는 §3 표, 화면에서 사용자 조정 가능

## 7. 안전성 등급 (A–F)

배당이 앞으로도 유지될 가능성. 5개 요소 각 0–2점 + 위기 가점.

| 요소 | 2점 | 1점 | 0점 |
|---|---|---|---|
| 커버리지 (FCF) | ≥ 1.5배 | ≥ 1.0배 | < 1.0배 |
| 커버리지 (REIT·MLP OCF) | ≥ 1.4배 | ≥ 1.2배 | < 1.2배 |
| 커버리지 (배당성향 섹터) | 상한 −10%p 이하 | 상한 이하 | 상한 초과 |
| 부채 (순부채/EBITDA) | 섹터 한도의 70% 이하 | 한도 이하 | 한도 초과 |
| 이자보상배율 | 섹터 하한의 2배 이상 | 하한 이상 | 하한 미만 |
| 삭감 이력 | 없음 | — | `Cut_Flag` |
| 이익 안정성 (EPS 변동계수) | ≤ 0.2 | ≤ 0.4 | > 0.4 |
| 위기 가점 | 2008 금융위기 통과 | — | (미통과 시 요소에서 제외, 감점 없음) |

- 등급 = 받은 점수 / 가능한 점수: A ≥ 85% · B ≥ 70% · C ≥ 55% · D ≥ 40% · F 미만
- 데이터 있는 요소(위기 가점 제외)가 3개 미만 → N/A
- 해석: **A·B 핵심 보유 / C 관찰 / D·F 비중 축소·교체 검토**

## 8. 밸류에이션과 매수 시점

필터가 아니라 **신호로만 표시** — 좋은 종목을 비싸다는 이유로 숨기지 않는다.

- [표시] **배당률 백분위** (`Yield_Pctl_5Y`): 현재 배당률이 자기 5년 일별 배당률 분포에서 어디인지
  - ≥ 70 → **저평가** (배당률 상단 근처 = 주가 하단)
  - ≤ 30 → **고평가**
  - 그 사이 → 적정
- [표시] **수익률 함정** (`Yield_Trap`): 저평가인데 아래 중 하나 → "함정 의심"
  - 3년 EPS CAGR < 0 · 커버리지 < 1 · 삭감 이력
  - 배당률이 오른 이유가 주가 하락이고, 그 하락이 실적 악화 때문일 수 있음
- [표시] 5년·10년 평균/최저/최고 배당률 대비 현재 배당률 차이
- [표시] P/FCF, 순 자사주 매입 수익률, 주주환원수익률(배당 + 순매입)
- [표시] **매수 시점 참고 지표** (`Timing_Signal`, 데이터 갱신일 기준 — `Timing_As_Of`)
  - 20일 이동평균 대비 위치 (`Price_vs_MA20`), RSI 14일 (`RSI_14`), MFI 14일 (`MFI_14`)
  - RSI ≤ 30 또는 MFI ≤ 20 → **과매도** / 종가 < 20일 평균 → **20일선 아래**
- 매수 원칙
  - 기준 통과 종목 중 **저평가·적정 + 함정 아님** 우선
  - 그중 과매도·20일선 아래면 분할 매수 시점으로 참고 — 기술 지표만으로 사지 않는다
  - 적립식이면 시점보다 꾸준함

## 9. 포트폴리오 기준

`modules/portfolio_diagnosis.py`가 판정, 화면 "Portfolio Diagnosis"와 스킬이 공유.

| 점검 | 경고 조건 | config |
|---|---|---|
| 종목 소득 집중 | 한 종목이 배당소득의 **20%** 초과 | `PORTFOLIO_MAX_HOLDING_INCOME_SHARE` |
| 섹터 집중 | 한 섹터가 평가액의 **35%** 초과 (ETF 제외) | `PORTFOLIO_MAX_SECTOR_VALUE_SHARE` |
| 안전성 취약 | D/F/N/A 등급이 배당소득의 **25%** 초과 | `PORTFOLIO_MAX_WEAK_GRADE_INCOME_SHARE` |
| 삭감 이력 | 보유 종목에 `Cut_Flag` | — |
| 수익률 함정 | 보유 종목에 `Yield_Trap` | — |
| 지급월 공백 | 최근 12개월 배당락 기준 배당 없는 달 | — |
| 금융소득 종합과세 | 예상 연 배당 **₩2,000만** 초과 | `KR_FINANCIAL_INCOME_THRESHOLD_KRW` |

- 월배당 만들기: 분기 지급월이 다른 종목을 묶는다 (1·4·7·10 / 2·5·8·11 / 3·6·9·12)
- 분산: 일반 기업 + 리츠 등 다른 현금흐름 원천을 섞는다
- ETF는 등급을 매기지 않고 별도 표시(분산된 상품이므로 "취약"으로 보지 않음)
- [정성] 채권·금 등 비주식 자산 배분은 범위 밖 — 투자자 상황에 따라 조언 (§11)

## 10. 한국 투자자 관점

| 항목 | 기준 | 비고 |
|---|---|---|
| 미국 배당 원천징수 | **15%** (한미 조세조약) | 국내 추가 과세 없음 (종합과세 대상이 아닌 경우) |
| 해외주식 양도소득세 | **22%** (지방세 포함) | 연 **₩250만** 기본공제, 같은 해 손익 통산 |
| 금융소득 종합과세 | 이자+배당 연 **₩2,000만** 초과 | 초과분 누진세율 — 앱은 경고만, 계산하지 않음 |
| 환율 | USD/KRW (`KRW=X`) | 원화 기준 수익률 = 달러 수익률 + 환율 변화 |

- **어림 계산**: 미국 배당주에 ₩1억, 배당률 r% → 세후 월 배당 ≈ **r × 7만 원**
  - 예: 5% → 약 35만 원 (₩1억 × 5% × 0.85 ÷ 12)
- 백테스트 기본 세금 프리셋 = 한국 거주자, 원화 환산 보기 제공
- 계좌 유형: 앱은 **일반 계좌** 기준
  - [정성] 연금저축·ISA 등은 과세이연·세액공제·분리과세 효과가 있음 → 국내 상장 미국 ETF로 배당성장 투자 시 유리할 수 있음 (§11)
- 세금 정보는 일반 기준 — 실제 신고는 세무 전문가 확인

## 11. 정성 점검 체크리스트

데이터로 판정하지 않는 항목. 종목·포트폴리오 상담 시 해당되면 짚는다.

- **실적 방향**: 동반 성장 배지가 없으면 매출·이익 중 어느 쪽이 꺾였는지, 영업현금흐름은 양호한지
- **위기 이력**: 위기 미통과 종목은 당시 동결인지 삭감인지 실제 배당 내역으로 확인
- **리츠**: 신용등급, 입주율, 임대 만기 분포, 금리 민감도 — 리츠의 주된 위험은 배당 삭감보다 **주가 하락**
- **배당 이력이 짧은 고배당·고성장 종목**: 연속 증가 2–3년이면 수치가 좋아도 위험이 높다
- **커버드콜·고분배 ETF**: 총보수가 높고 연도별 분배금 편차가 크다. 횡보·하락장 현금흐름용이지 장기 성장용이 아님
- **자산 배분**: 채권·금 등 비주식 자산 비중, 리밸런싱 주기(예: 매년 1회)
- **계좌 선택**: 일반 계좌 vs 연금저축·ISA (과세이연·세액공제)
- **투자 목적 대비 트랙**: 지금 소득이 필요한지, 축적 단계인지 (§3)

## 12. 한계와 고지

- **생존편향**: 유니버스는 현재 살아남은 배당주 — 과거 백테스트 성과가 부풀려질 수 있음
- **데이터 출처**: StockAnalysis.com, Yahoo Finance(yfinance), FRED — 지연·결측·오류 가능. 데이터가 4일 넘게 갱신되지 않으면 화면에 경고
- **세금**: 일반 기준만 반영. 종합과세 누진 계산·외국납부세액공제·계좌별 특례 미반영
- **투자 권유 아님**: 기준 통과는 검토 대상이라는 뜻이지 매수 추천이 아니다
